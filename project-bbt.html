01

Overview

All About Bubble Tea! is a responsive website with multiple pages of information about bubble tea, from its culture to the different types of drinks, plus an interactive ordering mini-game.

The brief

Create a responsive website on a topic of our choice, using what we had learned in the module.

02

Key features

Responsive layout

Pages adapt across desktop and mobile screen sizes.

Drinks carousel

An image carousel showcasing different types of bubble tea, each with a short description.

Ordering mini-game

An interactive "Order your own bubble tea!" game built into the site.

03

My role

This was a solo project, so I designed and programmed the whole site myself.

Interactive features
  • Make Your Own Bubble Tea mini-game
  • Form submission
  • Fullscreen mode
  • Refresh button
  • UI hover tooltips
Content & animation
  • Types of bubble tea carousel
  • Bubble tea reviews
  • Timeline animation
  • Pop-up bubbles
04

Biggest challenge

Problem

Designing a layout that stayed responsive across screen sizes while still feeling fun and interesting.

Solution

I chose simpler designs so the pages would adapt more reliably, then kept them fun with interactive touches like the mini-game, animations and pop-up bubbles.

Reflection

What I learned

Next time, I would plan a structured layout for the whole website before writing any code. Along the way I kept running into problems figuring out how to make designs both responsive and appealing, and planning first would have avoided a lot of that.

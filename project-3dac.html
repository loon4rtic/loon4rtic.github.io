01

Overview

A third-person 3D action game built in Unity, focused on implementing unique movement and combat mechanics to create a fun combat-based experience.

The brief

Create a 3D third-person action combat game.

02

Key features

Bow combat

Third-person aiming and shooting with a bow.

Climbing

The game measures the height of each block and picks a matching climb animation, so the player lines up perfectly with the ledge.

Health system

An on-screen health bar tracks damage during combat.

03

My role

This was a solo project, so I programmed every system in the game myself.

Combat & movement
  • Hand-to-hand combat (punching)
  • Bow combat
  • Climbing system that measures block height and plays a matching animation
  • Animation switching: idle, walk, run and jump
World & presentation
  • AI enemies
  • Interactable items
  • Cinematic Unity shots
04

Biggest challenge

Problem

Managing my time. I had to balance this three-week assignment alongside the rest of my modules.

Solution

I set planned blocks of time each day for each assignment, which helped me divide my time more deliberately between them.

Overview

ONE RUN is a strategy-based deckbuilder made in Unity. Players build a deck and fight through turn-based card battles across a single roguelike run, where every choice counts. It's published on itch.io and plays in the browser with just a mouse.

Player reception

Rated 4.7 out of 5 on itch.io in its first week, with players calling it "so addictive" and recommending it to fans of Inscryption.

02

Key features

Deckbuilding

Build and refine your deck as the run goes on, choosing which cards to take into each fight.

Turn-based combat

Strategic card battles where planning each turn matters more than reflexes.

One roguelike run

Every run is a fresh attempt, so each decision has lasting consequences.
